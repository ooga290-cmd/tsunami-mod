# Tsunami Mod (Fabric 1.21.1)

มอดสึนามิสำหรับ Minecraft Java Edition 1.21.1 (Fabric)

## วิธีเล่น
พิมพ์คำสั่ง (ต้องเป็น OP / เปิดโหมดโกงในโลก):

| คำสั่ง | ทำอะไร |
|---|---|
| `/tsunami start` | สึนามิโผล่ไกลๆ ในทิศที่คุณมองอยู่ แล้วพุ่งเข้าหาคุณ |
| `/tsunami start <สูง> <ความเร็ว>` | กำหนดความสูง (10–200 บล็อก) และความเร็ว (บล็อก/tick, ค่าเริ่มต้น 0.9) |
| `/tsunami stop` | หยุดสึนามิทั้งหมด |
| `/tsunami destroy true/false` | เปิด/ปิดการทำลายบล็อก |

## สิ่งที่มอดทำ (ตามคลิป)
- กำแพงน้ำสูงเคลื่อนมาจากขอบฟ้า มีหน้าคลื่นสีน้ำเงินเข้ม ยอดคลื่นสีขาว และฟองที่ฐาน
- คลื่นกวาดทุกอย่างเหนือพื้นดิน (บ้าน ต้นไม้ พืช) ขูดดินออก 2–4 ชั้น แล้วทิ้งโคลนไว้
- บล็อกบางส่วนถูกเหวี่ยงลอยเป็นเศษในอากาศ
- ผู้เล่นและม็อบที่อยู่ในคลื่นจะถูกพัดไปตามคลื่นและโดนดาเมจ
- หน้าจอเป็นสีเขียวขุ่นตอนอยู่ในคลื่น (ต้องติดตั้งมอดฝั่งผู้เล่นด้วย)

บล็อกที่มี block entity (หีบ เตาหลอม ฯลฯ), bedrock และ obsidian จะไม่ถูกทำลาย

## วิธี build
1. ติดตั้ง JDK 21 และ Gradle 8.10+ (หรือเปิดโฟลเดอร์นี้ด้วย IntelliJ IDEA แล้ว import Gradle)
2. รัน `gradle build`
3. ไฟล์มอดอยู่ที่ `build/libs/tsunami-mod-1.0.0.jar`
4. ใส่ใน `mods/` พร้อม Fabric Loader 0.16+ และ **Fabric API** สำหรับ 1.21.1

ถ้า build แล้วเวอร์ชันไหนหาไม่เจอ ให้เปิด https://fabricmc.net/develop เลือก 1.21.1 แล้วคัดลอกเลขเวอร์ชันมาแก้ใน `gradle.properties`

## ปรับแต่ง
ค่าทั้งหมด (ความกว้าง ความหนา ดาเมจ ระยะเริ่มต้น) อยู่ใน `TsunamiSettings.defaults()`
